# Concave Support Desk — Design Deliverables

This folder contains the Day 2 design submission artifacts.

## Contents
- `01_user_flows.md` — primary user journeys and screen flow
- `02_database_design.md` — entities, relationships, constraints and ER diagram
- `03_system_architecture.md` — application architecture and component responsibilities
- `04_business_rules.md` — SLA, priority, escalation, reopening and assumptions

## Design baseline
- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: PostgreSQL
- Architecture: Modular monolith with a background scheduler
- Time storage: UTC; display timezone: Asia/Kolkata

These are the initial Day 2 design artifacts. If the implementation later requires changes, preserve these files and add dated/revisioned documents rather than silently replacing the submitted design.
